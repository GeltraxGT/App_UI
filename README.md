# App_UIs

Collection of app UIs, under `GeltraxGT/App_UI`.

- Local workspace: `~/workspace/App_UIs/`
- GitHub: https://github.com/GeltraxGT/App_UI.git
- Each app UI lives in its own folder under `apps/`.

## Skills — workspace-local only

Skills installed for this workspace live **only** here, in
`App_UIs/.agents/skills/` as real directories. They are **not**
installed globally (`~/workspace/custom-skills/`) and this workspace
does **not** symlink the global harness bundles.

See `SKILLS.md` for the installed-skills registry, and `AGENTS.md`
for the rule.
